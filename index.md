# Index

Every folder in this repo. Each concept folder has its own `index.md` that lists its pages.

## Concepts

- [Systems](systems/): one page per system, with its owner, dependencies, recent changes, open issues, incidents and drift from spec.
- [Teams](teams/): one page per team, with what it owns and what needs attention.
- [Decisions](decisions/): one page per decision, with the options, the reasons and who decided.
- [Runbooks](runbooks/): how to recognize and fix a known kind of problem, learned from incidents.
- [Skills](skills/): agent skills on how to change each busy system safely.
- [Digests](digests/): one summary per week.

## Records

- [Pull requests](prs/): one file per merged pull request.
- [Issues](issues/): one file per issue from Linear or Jira.
- [Incidents](incidents/): one file per resolved incident.
- [Specs](specs/): one file per PRD, RFC or technical design.
- [Discussions](discussions/): one file per chat thread.

## Everything else

- [Inbox](inbox/): drop pasted text or files here for Ingest inbox to sort.
- [Archive](archive/): inbox items that have been processed.
- [Types](types/): one definition per type, with the fields it uses.
- [Workflows](workflows/): the workflows that keep this repo current.
