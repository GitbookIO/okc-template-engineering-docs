The inbox is where new material goes when no connection brings it in: pasted notes, transcripts, documents, links.

Add one file per item. Ingest inbox reads each new file, writes the records it describes, and moves the original to `archive/`. The refinement workflows then update the concept pages from those records, each on its own branch for review.

This example stays here so the workflow graph shows the inbox. Ingest inbox never moves it.
